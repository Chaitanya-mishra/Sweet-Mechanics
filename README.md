# 🍰 Sweet Mechanics

A modern, responsive bakery landing page built using **HTML**, **CSS**, and **JavaScript**.

Designed with a soft, elegant aesthetic inspired by boutique home bakeries, featuring smooth animations, responsive layouts, product showcases, testimonials, and a contact section.

---

## ✨ Features

* Responsive Design
* Modern Hero Section
* Animated Statistics Counter
* Featured Products Showcase
* About Us Section
* Gallery Section
* Testimonial Slider
* Contact Form
* Mobile Navigation Menu
* Scroll Reveal Animations
* Smooth Hover Effects
* Lightweight & Fast
